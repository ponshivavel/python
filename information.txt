File Handling in Python

File handling is the process of creating, reading, writing, appending, and deleting files using Python.

1. Opening a File

Use the open() function.

Syntax:

file = open("filename.txt", "mode")
File Modes
Mode	Description
"r"	Read (default)
"w"	Write (creates a new file or overwrites existing content)
"a"	Append (adds data to the end of the file)
"x"	Create a new file (fails if the file exists)
"rb"	Read binary files
"wb"	Write binary files
2. Reading a File
Read the entire file
file = open("sample.txt", "r")
content = file.read()
print(content)
file.close()
Read one line
file = open("sample.txt", "r")
print(file.readline())
file.close()
Read all lines
file = open("sample.txt", "r")
lines = file.readlines()
print(lines)
file.close()
3. Writing to a File
file = open("sample.txt", "w")
file.write("Hello, Python!")
file.close()

Output in sample.txt:

Hello, Python!
4. Appending to a File
file = open("sample.txt", "a")
file.write("\nWelcome to file handling.")
file.close()

Output:

Hello, Python!
Welcome to file handling.
5. Using with Statement (Recommended)

The with statement automatically closes the file.

with open("sample.txt", "r") as file:
    print(file.read())

Writing using with:

with open("sample.txt", "w") as file:
    file.write("Learning Python")
6. Checking if a File Exists
import os

if os.path.exists("sample.txt"):
    print("File exists")
else:
    print("File not found")
7. Deleting a File
import os

if os.path.exists("sample.txt"):
    os.remove("sample.txt")
    print("File deleted")
else:
    print("File does not exist")
Example Program
# Write to a file
with open("student.txt", "w") as file:
    file.write("Name: John\n")
    file.write("Age: 20\n")

# Read the file
with open("student.txt", "r") as file:
    print(file.read())

Output:

Name: John
Age: 20
Best Practices
Use the with statement to automatically close files.
Handle exceptions using try and except for safer file operations.
Choose the correct file mode (r, w, a, etc.) based on your needs.
Close files if you are not using the with statement.
Exception Handling Example
try:
    with open("sample.txt", "r") as file:
        print(file.read())
except FileNotFoundError:
    print("The file does not exist.")

This covers the essential file handling operations in Python: opening, reading, writing, appending, checking existence, and deleting files.

OOPs in Python

OOP means Object-Oriented Programming. It is a programming style where we organize code using classes and objects.

Python OOP has 4 main concepts:

Class
Object
Encapsulation
Inheritance
Polymorphism
Abstraction
1. Class

A class is a blueprint or template for creating objects.

Example:

class Student:
    name = "Pon"
    age = 20

Here Student is a class.

2. Object

An object is an instance of a class.

Example:

class Student:
    name = "Pon"
    age = 20


s1 = Student()

print(s1.name)
print(s1.age)

Output:

Pon
20

s1 is an object of the Student class.

3. Constructor (__init__)

The constructor is a special method that runs automatically when an object is created.

Syntax:

class ClassName:
    def __init__(self):
        # code

Example:

class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age


s1 = Student("John", 21)

print(s1.name)
print(s1.age)

Output:

John
21
What is self?

self represents the current object.

Example:

self.name = name

means:

object.name = value
4. Methods in Class

Functions inside a class are called methods.

Example:

class Student:

    def __init__(self,name):
        self.name = name

    def display(self):
        print("Student Name:", self.name)


s1 = Student("Alex")
s1.display()

Output:

Student Name: Alex
5. Instance Variables

Variables that belong to an object.

Example:

class Car:

    def __init__(self, brand):
        self.brand = brand


c1 = Car("BMW")
c2 = Car("Audi")

print(c1.brand)
print(c2.brand)

Output:

BMW
Audi

Each object has its own data.

6. Class Variable

A variable shared by all objects.

Example:

class Student:

    college = "ABC College"

    def __init__(self,name):
        self.name = name


s1 = Student("Ram")
s2 = Student("John")

print(s1.college)
print(s2.college)

Output:

ABC College
ABC College
