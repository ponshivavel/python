# Python Programming & Data Science Learning Repository

Welcome to the **[python](https://github.com/ponshivavel/python)** repository! This repository contains a structured collection of Python scripts, Jupyter Notebooks, and practice files covering Python fundamentals, core data structures, functions, file handling, and essential Data Science libraries like NumPy, Pandas, and Matplotlib.

---

## 📂 Repository Structure

### 🔹 1. Python Basics & Core Concepts
* **`CH1_basic_input_and_ouput.py`**: Basic input and output operations in Python.
* **`CH2_type_converstion.py`**: Type casting and data type conversion examples.
* **`CH3_loop.py`**, **`CH3_nestedfor.py`**, **`CH3_while.py`**: Control flow covering `for` loops, nested loops, and `while` loops.
* **`CH4_complexnumber.py`**: Complex number arithmetic and operations.
* **`CH5_string.py`**: String manipulation and built-in methods.

### 🔹 2. Data Structures
* **`CH6_list.py`**, **`CH6_list1.py`**, **`CH6_list2.py`**, **`CH6_list3.py`**: Working with lists, indexing, and list methods.
* **`CH7_tuple.py`**: Immutable sequence types and tuple operations.
* **`CH8_set.py`**: Set operations and unique element manipulations.
* **`CH9_dictionary.py`**: Key-value pair mappings and dictionary methods.

### 🔹 3. Functions & Scope
* **`F1_functions.py`**, **`F2_functions.py`**, **`F3_functions.md`**: Defining functions, handling parameters, and return values.
* **`Scope.txt`**: Variable scope definitions (Global vs. Local).

### 🔹 4. Mini Projects & Utilities
* **`filehandling.py`**: Reading from and writing to text files.
* **`lcm.py`**: Script to calculate the Least Common Multiple (LCM).
* **`app.py`**: Application entry point script.
* **`modulesummary.md`**: Summary notes on Python modules.

### 🔹 5. Data Science Notebooks
* **`Numpy/`**: Array manipulations, indexing, and mathematical operations.
* **`Pandas/`**: Data analysis, Series, DataFrames, and data cleaning.
* **`Matplotlib/`**: Data visualization, plotting graphs, and customization.
