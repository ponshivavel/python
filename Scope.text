                LEGB Scope Rule
┌──────────────────────────────────────────────┐
│                Local Scope (L)               │
│  Variables inside the current function       │
│                                              │
│  def fun():                                  │
│      x = 10                                  │
│                                              │
│  Python searches here FIRST                  │
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │         Enclosing Scope (E)            │  │
│  │ Variables in the outer function        │  │
│  │                                        │  │
│  │ def outer():                           │  │
│  │     y = 20                             │  │
│  │     def inner():                       │  │
│  │         ...                            │  │
│  │                                        │  │
│  │ ┌──────────────────────────────────┐   │  │
│  │ │        Global Scope (G)          │   │  │
│  │ │ Variables outside all functions  │   │  │
│  │ │                                  │   │  │
│  │ │ x = 100                          │   │  │
│  │ │                                  │   │  │
│  │ │ ┌────────────────────────────┐   │   │  │
│  │ │ │     Built-in Scope (B)     │   │   │  │
│  │ │ │ Python predefined names    │   │   │  │
│  │ │ │                            │   │   │  │
│  │ │ │ print()                    │   │   │  │
│  │ │ │ len()                      │   │   │  │
│  │ │ │ sum()                      │   │   │  │
│  │ │ │ max()                      │   │   │  │
│  │ │ └────────────────────────────┘   │   │  │
│  │ └──────────────────────────────────┘   │  │
│  └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘

















┌───────────────┐
│ Local (L)     │
└──────┬────────┘
       │
       ▼
┌───────────────┐
│ Enclosing (E) │
└──────┬────────┘
       │
       ▼
┌───────────────┐
│ Global (G)    │
└──────┬────────┘
       │
       ▼
┌───────────────┐
│ Built-in (B)  │
└───────────────┘
